## 1. 架构与接口冻结

冻结的 Stage 1/Stage 2 公共链路为：

```text
Continuous world trajectory
  -> ContinuousWorldPacketSource (15 Hz, 1 s / 16 points)
  -> models.reference_packet.ReferencePacket (world frame)
  -> AsyncReferenceBuffer
  -> current/future reference interpolation at 120 Hz
  -> Stage 1 DSLPID or Stage 2 TD3ReferenceTracking
  -> MotorActionCodec(asymmetric_rpm)
  -> PyBullet
```

Stage 1 与 Stage 2 只允许下层控制器不同。正式链路不使用
`models.hierarchical_async.AsyncReferenceCache`，也不使用 legacy generator、Upper
planner、latent 或 `TD3HierarchicalAsync`。

控制时间冻结为：

```text
sim_time = k / 120
control_time = sim_time + 1/120
current reference = sample(control_time)
future reference = sample(control_time + 0.2 s)
```

## 3. Stage2-v1 external lower-controller 接口

`TD3ReferenceTracking` 新增并冻结 `reference_source=legacy|external_packet`。
`external_packet` 模式满足：

- 只接受 `models.reference_packet.ReferencePacket`；
- 只通过 `AsyncReferenceBuffer` 消费 reference；
- 禁止调用 `RuleReferenceGenerator` 和 `_refresh_reference()`；
- 锁定 `asymmetric_rpm`；
- 锁定 `lower_action_history_steps=0`；
- Packet 无效时不调用 Actor，执行上一实际动作乘 0.85 的显式 fallback；
- Actor-only validator 中 teacher intervention 必须为 0。

Stage2-v1 context 合同标识为：

```text
stage2_v1_external_packet_30d
```

30D 包含 12D 当前运动状态、6D current-reference error、6D future-reference error、
Packet age/valid 两维和上一周期 4D motor action。这里没有多步动作历史。

## 4. Pilot 数据与标签歧义诊断

建立了独立于历史 BC collector 的 Stage2-v1 collector，首轮 pilot 使用 3 个 seed、
hover 与 7 m straight，共 6 episodes、14,955 transitions。所有 teacher rollout gate
通过，context reconstruction error 为 0，motor saturation 与 fallback 均为 0。

Pilot 暴露出 stateful DSLPID 的监督合同问题：同一冻结 30D context 没有包含 PID 积分
状态与 `last_rpy` 历史，因此理论上可以对应多个 teacher label。反事实分析确认主要影响
来自位置积分和姿态速率历史，而非姿态积分。

## 5. Canonical teacher 去歧义

比较了三种 teacher：

| Teacher | 3 seed × hover/straight | 结论 |
| --- | ---: | --- |
| Stateful DSLPID | 6/6 | 闭环可用，但标签依赖隐藏状态 |
| Canonical zero-rate | 1/6 | 缺少姿态速率反馈，不可用 |
| Canonical world-angular-velocity | 6/6 | 通过并采用 |

最终 teacher 合同：

```text
teacher_contract_id = stage2_v1_canonical_dslpid_world_rate
target = current_reference(control_time)
integral_pos_e = 0 before every label
integral_rpy_e = 0 before every label
last_rpy = infer_previous_attitude(cur_quat, world_ang_vel, dt)
```

该方式不改变 30D context 或网络结构，但使标签成为当前显式可观测输入的确定函数。

## 8. 今日发现并修复的问题

第一次正式采集生成的 canonical v1 中，审计字段 `state_quaternion` 每步被重复追加，导致
该字段样本轴为其他字段两倍。控制 rollout 与 teacher label 未受影响，但独立标签重算因
索引错位产生约 73.7 RPM 的伪偏差。

处理方式：

- 不放宽重算阈值；
- 不原地修补 v1；
- 保留 v1 与失败报告作为追溯证据；
- collector 增加所有字段 sample-axis 一致性硬断言；
- 从头重新采集 v2，并重新运行全部质量 gate。
