# Full FT v1：解冻前 Critic 与首次 Actor 更新审计

**关键回答：4k Full转移后的冻结期Critic尚不能可靠评价预训练Actor和候选动作。解冻前已存在显著价值低估与排序错误，解冻后的大幅Actor输出变化又迅速破坏闭环导航。** 这是不同于此前5k高估的阶段，不能把“4k已严重高估危险动作”或“4k完全正确，解冻后才出问题”当成结论。

## 复现依据与快照

## 4k价值与动作排序

每个seed复用192个成功Full预热状态，按Stage0/3和三维距离分层。回报校准另选12个源Actor成功轨迹状态：Stage0/3 × 地图80/88 × 起点、第60步、首次进入1.2m球。六类候选为源动作、第1/10次更新的动作、5k动作、4k Q1最高候选和4k min-Q最高候选。

**只改变第一步动作，后续全部交给同一个冻结源Actor，保留原12秒剩余时限。** 因而4k Critic与真实回报的后续策略一致；4k目标Actor也等于源Actor。真实回报 `G = sum(0.99^k × 0.1 × r_k)`，120Hz积分后按15Hz上层转移折扣，不额外按下层tick折扣。

| 源动作的12状态平均值 | seed43 | seed45 |
| --- | ---: | ---: |
| 4k Q1 | 0.556 | 0.131 |
| 4k Q2 | 0.580 | 0.242 |
| 4k min(Q1,Q2) | 0.546 | 0.120 |
| 真实Full折扣回报G | 11.434 | 10.377 |
| Q1 − G | −10.877 | −10.246 |

Q1、Q2和min Q均大幅低估源成功策略。以下比较候选与源动作的**Q1排序**，真实G差不超过0.05的配对视为近似平局，不纳入错误比例。

| 候选动作 | seed43错误/可区分配对 | seed45错误/可区分配对 |
| --- | ---: | ---: |
| 第1次更新后的动作 | 4/7 | 1/5 |
| 第10次更新后的动作 | 7/10 | 5/9 |
| 5k动作 | 7/11 | 3/8 |
| 4k Q1最高候选 | **6/10** | **5/7** |

4k Q1在两seed的全部12个状态上都偏好自身最高候选，但分别6/12、5/12的真实G明显更差。这些候选不是每次都差，近目标的一次制动/偏离也可能改善随后源策略的捕获；最高候选平均G差为+0.034/+0.067，不能据此声称它们全部危险。

**全部144条确定性单步分支最终成功。** 源策略能纠正单次扰动，不代表持续使用新Actor仍成功。其他时刻Q也已对同一组动作保存；解冻后Critic的后续策略已经变化，所以不能直接把“继续源Actor”的G当成后期Critic针对自身策略的校准，5k自身策略校准见上一份报告。

## 正式奖励积分审计

生产入口Full用 `integration_dt=1/120`，K1才用 `8/120`。Full将每个上层动作至多八个下层tick奖励求和，提前终止也只计实际tick，Replay再乘一次0.1。

| 原40k训练日志 | seed43 | seed45 |
| --- | ---: | ---: |
| 上层转移 | 40000 | 40000 |
| 下层tick | 318532 | 318627 |
| 上层奖励与下层和最大差 | 1.17×10⁻¹³ | 5.68×10⁻¹⁴ |
| 完整episode时间积分核查 | 341 | 302 |
| 时间积分最大差 | 1.11×10⁻⁷ | 1.11×10⁻⁷ |

时间惩罚核对 `0.25 × 实际非终止tick / 120`，微小误差来自TensorBoard浮点存储。两个5k复现另逐转移验证下层求和、时间惩罚和 `progress − continuous penalties + terminal outcome` 恒等式，最大恒等式误差8.88×10⁻¹⁶。终止tick按原定义只给终止项。

之前诊断工厂误用K1步长导致的八倍连续惩罚错误，**不在正式Full训练聚合中**，此前中间诊断已纠正，不能解释本次微调失败。

## 改进方向与证据边界

应同时验证**解冻前Critic的实际价值校准/排序准入**与**限制Actor偏离源策略的更新**。可检验更小Actor学习率、源策略动作保持约束或分层解冻，尚未证明最优。不能仅把冻结期延长便假定成功，也不能仅看TD loss下降便解冻；应结合真实Full G、近目标径向/垂直漂移与Stage0保留。

本次证明解冻前已有缺陷，并定位很早的Actor更新破坏性能；尚未用“只改善Critic”和“只减小Actor步长”消融分离各自贡献，不能宣称只修一项必然成功。当前没有改奖励、观测、GRU结构或Full物理参数，也没有启动新的40k微调。
