# 20×10m EGO 风格森林：课程、配置与冒烟设计

2026-10-13。状态更新：新配置`full_scratch_ego20x10_curr_v1`、地图划分和课程已实施，seed43完成2k并完整续到6k。工程契约通过，但在线学习出现垂直饱和/越界，暂不扩展预算。详见[实现与P0结果](2026-10-13_full_scratch_ego20x10_curr_v1_p0.md)。以下保留实施前设计作为协议依据。基线沿用已验证的 Full scratch 网络、动作、奖励和更新机制；本轮首先把地图与课程接通。

## 需要补齐的四块

1. **多地图采样与冻结几何。** 已交付的是 seed43 的一个开发实例。训练需要独立地图池，reset 时切换实例；观测仍来自 PyBullet rays，完整几何和 QA 路径不输入 Actor/Critic。
2. **矩形地图的可配置起点课程。** 替换原来写死的7m bands，支持静态圆柱记录、矩形路径检查和正确的 Full 重定位 reset。
3. **密度课程。** 难度从实际激活树木数确定，不能复用原来的挡路树数量标签。课程计数、成功 Replay 分层及评估也应使用同一个主难度定义。
4. **独立配置、评估与完整续训。** 新目录、新协议指纹、新地图 sampler 状态，保证长训从通过冒烟的原始学习状态接续。

## 地图配置与划分

基线任务尺寸20×10m，起点[-8,0,1]、目标[8,0,1]，树干直径0.4–0.6m，高3–4m，中心最小间距1m，位置采样网格0.1m，原感知范围1.75m。40s episode预算，成功球0.2m。几何保持解析圆柱，不把0.1m位置网格误当成0.1m精度的碰撞/测距。

建议冻结以下实例池；数量是初始协议建议，需要按实际生成和几何校验情况落实：

| split | 目标数量 | 生成候选 seed 范围 | 用途 |
|---|---:|---|---|
| train | 128 | 1000–1999 | 训练reset独立采样 |
| validation | 20 | 2000–2499 | 周期评估、best选择 |
| test | 40 | 3000–3499 | 协议冻结后的最终验证，不用于调参/选模 |

按候选seed顺序生成，在训练前用相同几何条件筛选前N个可行实例；记录所有拒绝seed和原因。数量不足直接报错，不跨到其他split或按模型成绩挑图。现有开发seed43不混入这些池。训练 seed42/43/44/45决定网络、探索及采样过程，环境地图seed决定几何，两者独立记录。

每个实例先生成40棵完整树池，使用固定、可复现的树木激活顺序构造10/20/30/40棵嵌套子集。保存完整池hash和每个stage的激活列表/hash。每阶段的起点/目标、安全间隙、域边界与可行路径在训练前校验，分别缓存该阶段QA路径。全树集合可行意味着其障碍子集保留该路径，但较稀疏阶段的可用路径与路径长度仍应分别记录。

QA采用无人机尺寸膨胀、附加0.20m净空和明确栅格分辨率。动态可行性另做Full实测，不能把BFS通过当成高速飞行保证。ray、collision和clearance必须指向当前实际激活的同一批圆柱；停用树木应移除其碰撞体，不能只隐藏视觉模型。

## 起点课程

在密度Stage0（10棵树）上推进距离，四档后进入原始起点级：

| 起点级 | 沿当前可行路径的剩余长度 | 原始起点保留概率 |
|---|---|---:|
| L0 | 0.35–1.2m | 20% |
| L1 | 1.2–4m | 20% |
| L2 | 4–8m | 30% |
| L3 | 8m–该地图该阶段完整可行路径长度 | 50% |
| L4 | 原始[-8,0,1] | 100% |

范围按路径剩余长度计算，不把欧氏目标距离和绕障路径长度混用。每张图的L3上限独立计算，不能把全部地图硬设为16m或沿用开发seed43的17.14m。

初始晋级门槛复用基线：窗口100个当前band回合、最少100个当前band回合、成功率≥70%、碰撞率≤20%。原始起点混合回合及fallback不推动短起点级晋级。晋级时重置该级窗口。实际L4编号可保留为4，但代码应使用“起点课程完成”状态判定障碍解锁，避免将来增加band后误用固定编号。

实现需要将 `StartDistanceCurriculum`、bands和保留概率参数化，旧配置继续使用旧参数。当前 `path_start_candidates` 仅接受旧 `xy/radius` 树木记录并使用正方形BFS；需要支持静态圆柱规格和矩形bounds。候选点要检查当前位置碰撞和净空。重定位之后清理UAV速度/角速度/姿态、PID、reference/packet、command、历史和奖励前一位置/距离。

## 障碍密度课程

| 密度级 | 实际激活树木数 | 名义密度 |
|---|---:|---:|
| Stage0 | 10 | 0.05株/m² |
| Stage1 | 20 | 0.10株/m² |
| Stage2 | 30 | 0.15株/m² |
| Stage3 | 40 | 0.20株/m² |

在L4之前，密度固定Stage0；在L4之后，起点固定原始16m，再按密度级晋级。初始门槛复用基线：窗口/最小回合100，Stage0→1/1→2/2→3的成功阈值80%/75%/70%，碰撞上限15%/20%/20%。只有原始起点、当前主密度级的完整回合可以进入门槛窗口。

第一版关闭所有容易密度级混合，只保留上述起点课程内的原始起点混合。这是新密度协议的显式选择，避免无意引入旧atlas或wrapper的simple mix。若后续要加容易密度保留，应明确概率、采样分布及“回合可进入Replay但不得推动主密度晋级”的规则，另登记变更。

成功Replay沿用20k容量和20%混合比例，但分层键改为实际10/20/30/40树主难度，各层5k。不再使用`route_blocking_tree_count`，该字段在当前EGO风格地图里为0。日志必须记录 `density_stage`、`active_tree_count`、`primary_difficulty`、起点级/source、geometry hash及终止原因，避免课程统计只改标签却实际仍生成40棵树。

## 候选训练配置

| 项目 | 第一版建议 |
|---|---|
| 模式 | Full/DSLPID，Recurrent TD3从零初始化 |
| 网络/观测 | 沿用917D、8帧语义历史、独立Actor/Q1/Q2 GRU |
| 初始状态 | 不加载K1、Full FT或旧7m训练权重/优化器；无Actor冻结 |
| 决策/执行 | 15Hz / 120Hz，每完整上层步8个真实下层tick |
| 动作 | 三维速度命令，沿用XY投影，平面0.8m/s、垂直0.3m/s上限 |
| reward | 原terminal-guidance参数，连续项按1/120s积分，真实tick求和；reward_scale=0.1 |
| Replay | 主60k；成功20k，按10/20/30/40树分层 |
| start_timesteps / update_after | 5000 / 5000 |
| batch / delayed policy update | 256 / 每2次Critic更新一次Actor |
| 初始Actor/Critic LR | 3e-4 / 3e-4，沿用原保守阶段切换规则并记录 |
| gamma | 首次沿用0.99，单独记录更长任务的回报标定；不先改奖励或GRU |
| 时间/终点 | 40s / 0.2m |
| checkpoint/周期评估 | 每5k，保存raw网络和完整训练状态 |
| 冒烟累计预算 | 先2k，再用同配置续到6k |
| P1预算 | 冒烟通过后先看10k，再看20k；不自动启动240k |

40s/15Hz约允许600个上层完整决策；旧环境的严格`>`超时判断可能多执行一个终止部分tick，应按实际tick验证，不能假定每个timeout恰好600条。16m/0.8m/s的理想直线时间约20s，gamma=0.99的终点折扣约0.049；进展奖励仍有信号，但长时域价值估计要单独检查。

新模式不能复用旧`full_scratch_curr_v1`实验名或旧快照。输出路径建议统一使用 `full_scratch_ego20x10_curr_v1_seed43`，验证前不得覆盖任何旧目录。观测维度与算法结构保留，地图尺度使全局位置/目标输入分布改变，日志应记录范围/有限值；对从零训练这是新任务输入分布，不能把旧模型零样本失败直接当成算法不可学。

## 冒烟分三层，不能只看终端是否报错

### A：地图、reset和课程契约检查

在独立测试实例上覆盖5个起点级×4个密度级，至少3张不同几何；L0–L3+Stage1–3的组合只作测试注入，不代表正式课程会走这条路径。每个组合reset后执行少量Full步，再reset，检查状态没有跨回合残留。

验收：

- 树木真实碰撞体数量精确为10/20/30/40，ray和净空只见当前激活集；矩形边界有效，起终点无碰撞。
- 每个band的实际剩余路径长度在区间内；不能频繁默默fallback到原始起点。采样失败必须记录geometry及原因，不能让课程形同虚设。
- reset后UAV运动、PID数值状态、reference/packet计数、动作/历史正确，917D观测有限且与真实起点一致。
- 通过独立合成outcome测试证明：近起点成功不晋级密度，旧stage回合不影响新窗口，只有当前主密度+原始起点回合晋级。测试专用小窗口和强制级别不得写入正式run的课程状态。
- 在独立Full近目标回合用确定性测试控制器获得真实success，验证整回合进入成功Replay、分层正确，碰撞/timeout回合不进入成功池。测试控制器轨迹只用于独立机制检查，不注入正式训练Replay。

### B：seed43生产配置2k工程冒烟

正式run从随机Actor/Critic、空Replay、L0/Stage0开始。每个回合从train池采样地图，保留原探索设置。保存完整首回合及实际出现的成功/失败回合上下层轨迹，并记录每条transition的map/stage/start身份。

沿用5k warmup时，2k内**网络更新次数为0**，这是预期，不得标记为Actor/Critic更新已验收。重点验收：

- reset、实际地图树数、逐tick packet/RPM、奖励求和、投影后Replay动作、917D历史移位、终止/超时语义全部一致。
- map sampler真实切换实例，访问集合属于train split；无validation/test地图进入Replay。
- 主Replay累计2000条，网络仍与初始化一致，课程统计与完整回合一致；预算截断回合不作为成功、不推动课程。
- 近目标随机探索是否获得成功、引导区覆盖、height/xy bound、timeout以及安全净空如实报告。无成功不会自动证明环境错误；需要A层成功Replay测试和下一层更新检查共同解释。
- 保存`model_raw_final`与完整训练状态，记录随机源、采样器游标/索引、课程窗口、map manifest hash、网络/target/Adam、Replay和累计步数。

### C：同协议续到6k，覆盖真正在线更新

从B层的原始完整快照继续，累计预算为6000，不能用普通权重加载或恢复selected checkpoint代替续训。启动前确认原2k数据、课程和学习状态保留；物理回合按已有设计重新reset，日志明确记录这一边界。

在不发生保守阶段切换、保持`policy_freq=2`的条件下，5k–6k应执行**1001次Critic更新、500次Actor更新**。检查网络参数实际变化、非空Adam状态、targets延迟更新、无冻结、梯度/TD/Q有限；根据计数精确判断，不只看TensorBoard出现loss。

还应对非空Adam和非同步target做独立保存/恢复测试：在同一批采样与相同RNG下，恢复分支的下一次更新与未中断分支一致。对2k/6k快照验证主/成功Replay和分层、课程窗口、地图sampler及随机源没有重置。

可以在2k Replay副本上提前做少量更新机制探针，降低等到5k才发现错误的成本；探针更新和轨迹不写回正式run。它只能作为补充，不能替代C层真实在线更新。

## P0通过标准与停下审计的条件

**硬工程门槛**：map几何/活跃树数/矩形边界一致、课程晋级正确、Fullreset状态正确、每步奖励和Replay语义一致、实际在线网络更新、完整续训恢复、旧7m回归与旧checkpoint保护。任一失败先修机制，不增加长训预算。

**学习观察门槛**：如6k近目标训练仍无成功，先检查初始band、控制响应、越界、timeout、动作偏置及奖励记录，决定是否进行有界的10k检查。10k–20k仍无法积累有效成功Replay时暂停预算扩展并定位瓶颈。P0不要求原始16m成功，不要求密度晋级，不强制达到某个学习成功率。

当前监测应补到新协议：逐更新Q1/Q2均值/标准差/范围、TD绝对误差均值与分位数；Actor轴饱和/XY边界、径向与垂直命令/实际速度，按近目标/远目标分组；固定共同状态集上的相邻checkpoint策略RMS，同时保留当前访问状态探针，避免只看P0旧状态。出现异常先核对实际树数、课程/Replay分层、终止mask、时间积分、更新/target/优化器和采样分布，再讨论奖励或GRU。

## 评估与产物安排

每5k在固定validation实例上做两类无噪声评估：当前密度+原始16m起点，以及固定Stage0/10树+原始16m起点。当前密度也是Stage0时可复用同一组结果，避免重复计算；近目标课程表现从完整训练回合另行统计。Stage3能力在进入Stage3后正式报告，不将其他stage的成功率标为Stage3。

建议各20张validation图，记录SR/CR/timeout、guidance进入、最终距离、实际速度、tracking和成功回合最小净空分位数。40s长回合使评估成本明显增加；如果要减少图数，应在正式长训前固定修改协议，不能看结果后挑图。最终独立test40图至少检验Stage0与Stage3，并区分selected和raw；不据test结果重新选checkpoint。

原始周期评估、末尾raw评估、恢复selected后的评估必须使用不同目录并标明来源step/hash，避免上一轮同step覆盖trace的问题。P0报告至少包含初始化证据、地图访问/分层计数、完整轨迹、网络更新和续训对比、课程门槛测试、所有失败原因、可复现配置和未完成事项。

## 最小实施边界

首先交付地图池/manifest、支持静态圆柱的矩形起点课程、密度激活器及晋级接口、成功Replay分层、新preset及完整续训/评估路径，然后执行A/B/C。本文件保留原设计；实施状态以页首链接的P0结果为准。
