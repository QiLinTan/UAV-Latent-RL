# 2026-11-18 几何与门洞补充验收

训练环境：/opt/uav-training-20261103/venv；项目 rv1_project；感知代码 ms_geometric_v1。所有结果为仿真与离线检查，不是飞行安全或训练性能结论。

- oracle_yaw_check.py: 用独立射线-轴对齐体素盒区间相交算法，分别对1、16、48条随机射线的单帧结果逐体素比较，参考版及加速版差异均为0。没有穷尽边界重合与所有退化情形。
- PyBullet固定墙：yaw从0°变为90°时，墙由局部+x方向变为-y方向；对应占用区域和测距断言通过。
- CF2X URDF主碰撞形状为半径0.06 m、长度0.025 m的圆柱；不是完整螺旋桨包络，也未计入安全裕量。
- door_sweep.py: 墙体中心距离0.8、1.2、2.0 m，门洞0.2、0.4、0.8 m。对于每个距离，0.2m与0.4m的250维近场输出逐维完全相同，远场52维分别有9、10、3维不同。0.8m距离时，0.2和0.4m开口的中心横向列都有3个占用体素；这些只是居中、固定姿态和固定网格结果，不能判断能否安全通过。需要移动网格相位、0.2m体素对照及实际包络评估。
- 历史100帧静态墙耗时：扫描到特征P50 16.37ms、P95 19.72ms；旧参考版RV1帧体素编码约0.85秒，非相同统计协议。新测试未计策略网络、并发训练或完整控制链，不是实时保障。
- 原方案0.4m暂未通过几何保真度验收；不建议进入正式训练。
