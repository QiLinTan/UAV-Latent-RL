# no_route 正式评估、动作审计与 Critic Q scan

## 实验对象和口径

评估 checkpoint：
`checkpoints/upper_dslpid_recurrent_multitree_terminal_v2_noroute_h8_k1/model_final`。
`model_final_selection.json` 确认它是恢复的 `model_best`，对应训练第 94,000 步，
不是 120k 结束时的最后网络。训练过程使用 seed 42；正式评估固定验证地图，独立运行
seeds 0–19，不启用探索噪声。

相对 Terminal-v2，唯一学习奖励参数变化为水平路线推进权重 `12 -> 0`；
三维目标推进权重仍为 8，terminal guidance、TD3、h8、K1、rayfix、地图、课程、
成功半径和终止奖罚不变。因此这是一次受控的单训练 seed 消融；随机训练波动仍意味着
不能只凭这一组训练证明普遍因果。

## 正式 20-seed 结果

| 指标 | Terminal-v2 | no_route |
| --- | ---: | ---: |
| success | 0/20 | **15/20（75%）** |
| collision | 0/20 | **0/20** |
| timeout | 17/20 | **5/20** |
| height bound | 3/20 | **0/20** |
| 进入 1.2 m 三维引导球 | 0/20 | **20/20** |
| 成功终止转移 | 0 | **15** |
| 平均最终三维距离 | 1.884 m | **0.248 m** |
| 平均绝对高度误差 | 0.975 m | **0.245 m** |

no_route 已经解决当前最主要的覆盖失败：飞机不再通过错误的高度轨迹留在1.2 m球外。
20局全部进入引导区，15局进入严格的0.2 m成功球，并且没有碰撞或高度越界。

5个失败回合全部被 timeout 诊断器归类为 T1（近目标徘徊或离开）。它们都进入过
1.2 m球，最近距离分别约为0.375、0.248、0.303、0.2033和0.2036 m；后两局只差
约3–4 mm，但按未改变的严格规则仍不算成功。它们最终距离为0.274–0.668 m，说明问题
已经从“无法接近”转变成“末端捕获不够稳定”。

成功回合在引导区内平均停留1.67秒，平均朝目标闭合速度0.627 m/s，远离目标的状态比例
约0.62%。timeout 回合平均停留3.08秒，闭合速度降至0.255 m/s，远离目标比例升至
37.3%。两组平均切向速度接近（0.178 对0.173 m/s），主要差异是径向方向是否持续正确。

## 训练过程和 checkpoint 选择

周期评估首次成功出现在40k。去除最终恢复 checkpoint 后，共57次周期评估，其中31次
出现成功、20次成功率至少50%；52k和92k各出现过一次10/10成功。后期性能仍有明显波动：
112k和114k的未选中网络分别降到0%成功。模型选择最终恢复94k checkpoint，训练时的
10局评估为80%成功，正式20局结果为75%。这说明分支有效，但训练稳定性还没有完全解决。

## 动作幅值与执行接口审计

正式评估内置审计记录5个T1回合的905次决策；额外三维扫描记录全部20局的3,352次决策。
Actor XY 动作到圆盘速度指令保持线性，实测最大映射误差为 `1.07e-7 m/s`；
K1下一步速度与加速度限制模型逐步一致。没有重新出现 Terminal-v1 之前的动作表示错误。

完整策略按三维目标距离分箱：

| 三维距离 | 平均水平指令 | 水平动作饱和率 | 平均实际水平速度 | 指令远离目标比例 |
| --- | ---: | ---: | ---: | ---: |
| 1.2–2.0 m | 0.798 m/s | 98.0% | 0.781 m/s | 0.0% |
| 0.8–1.2 m | 0.793 m/s | 96.7% | 0.789 m/s | 0.7% |
| 0.5–0.8 m | 0.693 m/s | 51.1% | 0.696 m/s | 11.5% |
| 0.2–0.5 m | 0.616 m/s | 29.3% | 0.355 m/s | **47.6%** |

策略已经能够进入末端区域，但在0.2–0.5 m仍给出较大的水平指令，而且方向频繁翻转。
成功与 timeout 在这个区间的平均指令幅值几乎相同（0.617 对0.615 m/s）；
timeout 的远离比例更高（58.7% 对38.1%），实际水平速度更低（0.255 对0.440 m/s）。
因此残余问题更像径向方向振荡和捕获时机，而不是单纯总速度过大。

## 内置末端 XY Q scan

内置扫描只针对5个T1 timeout，在三维距离0.3–1.2 m且树木 clearance 大于0.35 m的
151个状态中，固定 Actor 的 z 动作，比较停止以及沿 Actor/目标方向的多档水平速度。

- `min(Q1,Q2)` 的平均状态内跨度为2.040；最佳候选比 Actor 平均高0.466。
- 98/151个状态的最优候选速度仍不低于0.6 m/s。
- 在0.3–0.4 m范围，33/46个状态仍把不低于0.6 m/s判为最优。
- 最优候选中有23个状态选择停止，但没有形成稳定的“越近越慢”排序。

这和动作审计中的T1振荡一致：失败状态下 Critic 仍经常偏好较大的末端水平动作。

## 三维 Q scan 与实际续飞回报

为了避免只分析失败回合，另对20局重新采样144个真实状态：60个引导区外状态、
4个“XY近但三维距离仍在区外”的状态、80个引导区内状态。每个状态扫描136个可执行
三维动作，共19,584组Q1/Q2；Actor实际优化Q1，TD target使用双Critic较小值。

60个状态进行了437条“替换一步动作，然后原Actor继续到自然终止”的校验。
Actor基准续飞为45条成功、15条timeout，对应每个正式回合的三个分叉位置。

| 校验 | Q1 | min(Q1,Q2) |
| --- | ---: | ---: |
| 有效候选对中Q排序与实际回报排序一致 | 674/1286（52.4%） | 695/1276（54.5%） |
| 按该Q选出的候选成功数 | 47/60 | 50/60 |
| 相对Actor挽救timeout状态 | 3 | 5 |
| 使Actor成功状态变成timeout | 1 | 0 |
| 相对Actor的平均实际回报变化 | +0.859 | +2.562 |

Q排序在远距离成功续飞状态上相对较好：Q1候选对一致率63.9%。进入引导区后，
成功续飞状态降到50.7%，原Actor会超时的引导区状态仅44.1%。因此当前Critic的主要
薄弱点也从引导区外的高度价值，转移到了末端捕获动作的局部排序。

在15个Actor基准会timeout的分叉状态中，固定XY、仅把第一步z设为-0.30 m/s有7条
转为成功，但Q1只在2条中认为该动作更好；停止XY一步有6条转为成功，Q1只在3条中
认为更好。这些是单步扰动后由原策略续飞的结果，不能解释为“持续下降”或“持续停止”
就是部署控制器；它们表明Critic漏掉了一些能够改变后续轨迹并入球的局部动作。

## 当前结论

no_route 是目前第一个在同一K1 stage-0正式20-seed评估中同时达到高引导覆盖、明显成功率
和零碰撞的Terminal分支。相对于原Terminal-v2，删除水平路线推进项与三维接近恢复高度
一致，提供了很强的单seed消融证据；仍需要其他训练seed确认可复现性。

当前主要问题已经不再是“进不了1.2 m球”，而是5/20回合进入后不能稳定穿过0.2 m球：
末端水平指令偏大、径向方向频繁翻转，且Q1在失败引导状态中的局部排序仍不可靠。
下一步不应重新大改全程奖励。优先级应是：保留no_route主干，先做多个训练seed复现；
同时针对0.2–0.5 m状态检查径向/切向动作价值与成功转移采样。若复现后仍稳定停在75%左右，
再单独消融末端方向/速度塑形或提高成功附近transition采样，不能与其他结构改动同时进行。
