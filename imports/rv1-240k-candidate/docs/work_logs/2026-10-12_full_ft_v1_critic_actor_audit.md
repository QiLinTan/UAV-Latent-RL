# Full FT v1：Critic 价值排序与 Actor 更新幅度审计

后续补充：[解冻前 Critic 与首次 Actor 更新审计](2026-10-12_full_ft_v1_preunfreeze_causal_audit.md)已通过与原5k权重及全部前5k轨迹完全一致的复现，补齐0/3999/4000/4001/4019/4500/5000快照。新证据显示4k已存在显著价值低估和动作排序缺陷，首次/前10次Actor更新即破坏小规模闭环导航。下面保留原5k审计及当时的证据边界。

本次确认了两个问题：**Actor 解冻后发生过大的策略漂移；5k Critic 对当前策略的后续 Full 回报明显偏乐观，并存在真实动作排序错误。** 两者共同支持优先改进微调稳定性与策略保持。本次没有恢复出原始 4k Critic，不能确定第一次 Actor 更新之前的估值错误程度，也不能直接证明哪个问题最先发生。

## 范围与可比性

- 训练 seeds：43、45。源 Actor 来自四模型冻结目录；评估已保存的 5k、10k、20k、40k Actor/Critic。没有训练或优化器更新。
- 每个 seed 从 **4k 内已成功的 Full 训练回合**中抽取192个固定状态：Stage 0/3 × 3D距离 [0,1.2)、[1.2,4)、[4,∞) 各最多32个。所有 checkpoint 在完全相同的状态上比较动作与 Q，避免状态分布变化混入 Actor 漂移。
- 候选集合含源动作、5k动作、中间动作、悬停，以及8个朝向 × 3种水平速度 × 3种垂直动作，共76个可执行圆盘动作。单独读取 Q1、Q2、min(Q1,Q2)。Actor 原始优化目标是 Q1。
- 动态校验用原验证地图 seeds **80、88**、Stage 0/3。在每条源成功轨迹的起点、第60步、首次进入3D 1.2m球时分叉，每个 seed 12个状态，共24个状态、144条分支。
- 每次分叉均重新 reset 并执行相同源动作前缀。断言检查917D观测、位置、速度、参考位置/速度、树位置/半径和剩余仿真节拍。没有直接注入状态，也没有改变12秒终止或0.2m成功半径。
- **单步 Q 校验**：只强制第一步源动作或5k动作，随后两条分支均跟随同一个5k Actor。真实值为 `G = sum(gamma^t * reward_scale * r_t)`，其中 gamma=0.99、reward_scale=0.1。
- **15步校验**：执行15步源策略前缀，之后跟随5k Actor；与全程5k Actor比较。估计使用前缀真实奖励加 `gamma^H * Q(s_H, pi_5k(s_H))`，不把多步轨迹回报直接比较到初始单动作Q。
- 另有“第一步5k动作→之后源Actor”与“全程源Actor”对照，用于检查策略保持；这种对照不充当5k Critic的单步Q校准。

## Actor：第一笔更新就产生较大指令变化

4k内日志动作与源Actor重算动作的差异在1e-5以内。第4001步完成第一笔Actor更新，第4002步开始使用更新后的策略。把源Actor和记录的更新后Actor作用于**第4002步的同一个Full状态**，得到：

| 指标 | seed43 | seed45 |
| --- | ---: | ---: |
| 第一次Actor更新后的3D速度指令差 | **0.265m/s** | **0.369m/s** |
| 最大归一化动作轴差 | 0.881 | 0.438 |
| 5k Actor参数相对源参数的L2变化 | **6.52%** | **8.89%** |
| 5k Actor GRU参数相对L2变化 | 4.64% | 8.34% |
| 40k Actor参数相对L2变化 | 56.29% | 63.40% |
| 40k Actor GRU参数相对L2变化 | 47.23% | 54.45% |

相对参数变化定义为 `||theta_new-theta_source||_2 / ||theta_source||_2`；不是“改变了多少百分比的参数个数”。3D指令差是动作映射后的向量差，不是无人机实际速度瞬时变化；下层仍有加速度和动力学约束。

seed43第一笔更新的主要变化是垂直指令由约-0.138m/s变为+0.127m/s。到5k，两个Actor已各执行500次更新。

在固定的192个成功训练状态上，5k策略的行为变化为：

| 指标 | seed43 | seed45 |
| --- | ---: | ---: |
| 平均源→5k速度指令差 | **1.440m/s** | **0.657m/s** |
| 平均水平指令朝向差 | 137.97° | 51.84° |
| 源动作平均朝目标的3D径向速度 | +0.561m/s | +0.612m/s |
| 5k动作平均朝目标的3D径向速度 | **-0.726m/s** | +0.524m/s |
| 5k动作远离目标比例（径向速度<-0.02m/s） | **99.5%** | 13.5% |
| 5k动作平均垂直指令 | **+0.300m/s** | +0.008m/s |
| 5k垂直动作饱和比例（绝对值>0.95） | **100%** | 38.0% |

seed45的全体平均会掩盖近目标问题：在64个1.2m以内状态上，其5k平均垂直指令为 **+0.260m/s**，源Actor为-0.029m/s；平均3D朝目标速度由+0.441降到+0.102m/s，远离比例由6.3%升到39.1%。seed43更多表现为后退并持续爬升；seed45的近目标高度和方向控制明显改变。

## Critic：偏好更新动作不等于价值可靠

在同一组192个成功Full状态上：

| 5k Critic指标 | seed43 | seed45 |
| --- | ---: | ---: |
| Q1偏好5k动作的状态比例 | **99.5%** | **87.5%** |
| min(Q1,Q2)偏好5k动作的比例 | 99.5% | 73.4% |
| 平均Q1(5k动作)-Q1(源动作) | +3.646 | +0.709 |
| 动作漂移与5k Q1正梯度方向一致的比例 | 99.5% | 89.6% |

这个结果说明当前Actor的方向大体符合所测Critic的价值偏好，不能简单解释成Actor没有跟上Critic。但这里使用的是**已退化后的5k Critic**，没有把它冒充成第一次更新前的4k Critic。

### 单步排序核对

在12个动态分叉状态/seed上，用“一步候选动作→共同5k Actor”核对 Q 排序。只统计真实回报差绝对值>0.05且Q差绝对值>0.001的可区分对比：

| 指标 | seed43 | seed45 |
| --- | ---: | ---: |
| 可区分单步对比 | 12 | 7（另5个差异很小） |
| Q1与真实回报方向相反 | **5/12** | **4/7** |
| min(Q1,Q2)与真实回报方向相反 | **5/12** | **4/7** |
| Q1预计的平均“5k动作-源动作”优势，所有12个状态 | +3.794 | +0.168 |
| 实测相同后续策略下的平均优势，所有12个状态 | **+0.072** | **-0.159** |

这不是“所有单步排序都错”。例如seed43部分近目标状态中，一个更新动作后继续坏策略，回报确实略高于一个源动作后继续坏策略。它仍不足以恢复整条导航策略。与此同时，上述表中已存在严格同后续策略下的排序反例，而且双Critic取min没有消除这些反例。

### 绝对回报校准

对从同一诊断状态开始执行完整5k策略的分支，Q与实测值为：

| 指标（gamma=0.99，reward_scale=0.1） | seed43 | seed45 |
| --- | ---: | ---: |
| 平均初始Q1 | **+9.215** | **+0.725** |
| 平均实测折扣回报 | **-20.621** | **-25.728** |
| Q1平均高估 | **29.836** | **26.452** |
| min(Q1,Q2)平均高估 | 29.709 | 26.167 |

24条“继续源Actor”的诊断分支全部成功；24条“继续5k Actor”的诊断分支全部失败。这些是选定成功地图上的不同分叉状态，不是独立地图的正式成功率统计。

两个近目标例子：

- **seed43 / Stage3 / map80 / step127**：5k动作Q1=+22.147，而继续5k策略实际G=-35.657、发生碰撞。源Actor继续执行成功，G=+16.536。只将源策略执行15步再切回5k Actor也成功，G=+18.121。全程5k分支的近目标速度跟踪惩罚折扣累计为13.609，源分支为3.742。这组整条策略对照用于定位行为损失，不把源全程G直接当作Q(s,源第一步动作)的校准值。
- **seed45 / Stage0 / map80 / step125**：5k动作Q1=+0.784，继续5k策略实际G=-42.038并timeout。源Actor继续成功，G=+14.144。5k分支近目标速度跟踪惩罚折扣累计为31.309；源分支为2.185。只接回源策略15步后再切回5k仍timeout，G=-32.032，说明短暂正确动作并不足以替代完整的末端策略。

### 多步回报估计

15步前缀加共同5k后续策略的估计排序，与真实回报的方向相反：seed43 **5/12**，seed45 **2/12**。总体上，15步源前缀的真实回报分别平均高出7.338和8.867；Q1 bootstrap估计只给出5.079和2.986的平均优势。源前缀是否改善回报仍取决于分叉区域和随后坏策略的执行结果，因此报告保留逐状态结果，而没有只用总体均值宣称全部前缀有效。

## 能支持的解释与下一步

证据支持：

1. 本轮Actor解冻的更新幅度没有充分保护原有策略，整个Actor（含GRU）的变化很快影响到速度方向和末端高度控制。
2. 5k Critic没有可靠地表达更新后策略的失败尾段价值；单步排序存在反例，多步价值也有估计误差。有限的Critic loss不是解冻可靠性的充分条件。
3. 成功状态数据存在，但这些数据主要来自源策略成功动作及后续行为。它们并不能自动保证Critic对大幅改变后的动作和后续策略也估值正确。

因此下一轮应优先采用**更保守的Actor更新及明确的源策略保持**，并用真实Full回报和近目标价值校准约束解冻/后续更新，而不是仅按固定4k步数解冻。较小Actor学习率、动作保持约束、分层解除Actor冻结都是可检验的改进选项，尚未在本项目中证明最优。不能仅凭这次诊断断言延长Critic预热一定解决问题。

第一次更新前的4k Critic与目标Actor没有被保存，实际Actor梯度也没有逐更新记录。因此本次不能给出“首次错误梯度来自哪个具体参数”的精确因果重建。下一轮应在解冻前后保存更密的Actor/Critic/目标网络/优化器状态，并记录每段实际Actor更新计数与动作变化。

## 回报协议校验与限制

初版诊断工厂重用了K1的积分步长1/15秒，导致连续惩罚放大8倍。该错误只发生在本次中间诊断运行；原始Full训练使用1/120秒。所有最终144条分支已经在**Full的1/120秒**下按保存动作重新仿真，逐步核对位置/速度与终止结果，并验证：

- 相同源前缀的每步奖励与原Full验证轨迹奖励一致，绝对误差<=1e-5。
- 折扣回报与“折扣progress - 折扣continuous penalty + 折扣terminal outcome”一致，绝对误差<=1e-5。
- 所有分叉的初始观测、物理状态和参考状态一致。

因此正式结果使用重算后的回报；早期错误积分结果仅留在 `debug_wrong_reward_dt`，不参与本报告或最终汇总。新增4项测试覆盖Full积分步长、物理指令单位、bootstrap折扣关系以及单步/多步排序区别，全部通过。

重新闭环执行源策略时，seed43有2个诊断状态的成功时刻与旧日志相差上层步数，成功结果一致。由于浮点反馈可放大微小动作差异，排序比较使用本次统一CPU线程设置下的实际分支基线；分叉初态仍严格按旧动作前缀复现。

估值校准针对确定性的**当前在线Actor**。训练中的目标Actor滞后、目标动作噪声及观测缺少剩余时间会影响Q与有限剩余时长回报的差异。因此这里报告的是明确协议下的估值不匹配，未把每个Q残差都宣称为实现错误。只用了原验证seeds80、88，保留的40–79未使用。
