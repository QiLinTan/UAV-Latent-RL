# 分层异步参考序列控制实现与验证记录

日期：2026-07-27

## 实现目标

本实现将现有潜在表征、森林强化学习环境、异步 latent 原型和四电机 RPM
动作接口合并为一个可训练控制器：

1. 上层编码器读取完整森林观测并生成有界任务 latent；
2. 参考序列头从 latent 生成未来相对位置序列；
3. 上层结果写入带生成步、点间隔、有效期和版本号的异步缓存；
4. 上层每 8 个底层控制周期刷新一次；
5. 下层每个控制周期读取插值后的当前参考点和前视参考点；
6. 下层结合 12 维运动学状态、latent、参考点、信息年龄和有效标志输出四维 RPM 类动作；
7. 上层不可用时继续使用未过期缓存，缓存过期后输出零归一化 RPM 指令，对应悬停转速附近的安全降级。

## 默认配置

| 配置 | 数值 |
| --- | ---: |
| 底层控制频率 | 120 Hz |
| 上层更新间隔 | 8 个底层周期 |
| 上层等效更新频率 | 15 Hz |
| 参考序列长度 | 15 |
| latent 维度 | 16 |
| 缓存有效期 | 120 个底层周期 |
| 参考序列损失权重 | 0.05 |
| 参考平滑损失权重 | 0.01 |
| 上层 Actor 梯度比例 | 0.0 |
| Actor 动作幅值正则 | 0.02 |
| 四电机平衡正则 | 0.01 |
| 归一化 RPM 动作范围 | [-0.75, 0.75] |

第一阶段切断 Actor 对上层的梯度。上层由运动学重构、动作条件动力学预测和
障碍感知参考序列目标训练，下层由 TD3 训练。这是为避免非平稳的低层 Actor
在训练早期破坏上层表征。下层 replay buffer 额外保存动作执行时的真实
latent、参考点、前视点、缓存年龄、有效标志和上一电机动作，以及真实下一
上下文，不再在训练时随机重构异步 phase。

下层 Actor 使用“公共升力 + 有界电机差分”结构，并通过动作幅值、电机平衡和
相邻动作变化损失约束直接 RPM 指令。Actor 的 Q 项按批次 Q 绝对均值进行尺度
归一化，避免 Critic 数值长期漂移后淹没安全正则。

## 已完成验证

### 自动测试

- 异步参考点插值；
- 缓存有效期；
- 缓存版本更新；
- 参考序列输出形状和范围；
- 1:4 测试配置下的高层刷新节奏；
- 上层停更并超过有效期后的悬停等效动作；
- 随机 replay buffer 单步训练；
- 模型保存和加载；
- 原有森林观测布局及 affordance 回归测试。

结果：10 项测试通过。

### 第一版 10,000 步环境验证

稳定化版本运行结果：

- 参考序列损失：`0.05857 -> 2.79e-5`；
- 参考序列终点误差：`0.9445 -> 0.00471`；
- 参考平滑损失：`0.02060 -> 5.50e-6`；
- 缓存年龄覆盖 `0..7`，与每 8 步刷新一致；
- latent 各维平均标准差末值约 `0.100`，未发生早期版本的尺度爆炸；
- 训练批次 Actor 饱和率尾段为 `0`；
- 最后一次两回合评估平均回报约 `11.55`；
- 最后一次评估终点距离约 `6.77 m`，初始距离约 `7 m`。

该验证说明算法、异步缓存、参考序列学习、下层 RPM 输出、评估、日志及保存
链路均可运行。10,000 步不用于判断最终导航性能，50 万步实验仍需重点检查成功率、
碰撞率、终点距离和动作饱和。

### 第二版 30,000 步稳定性验证

针对第一版 50 万步后期 Actor 饱和问题，第二版完成真实异步上下文回放、电机
残差 Actor、Q 尺度归一化、安全边界惩罚、成功率课程门控和最佳模型保存。

- 15 项自动测试通过；
- 30,000 步内 Actor 训练饱和率始终为 0；
- 电机差分损失末值约 `0.017`；
- Q1、Q2 和 target Q 保持在约 `-0.3` 量级；
- Critic loss 末值约 `0.010`；
- 课程阶段保持为 0，没有被短失败回合错误推进；
- 三回合评估终点距离由 10,000 步的 `7.52 m` 改善到 30,000 步的 `4.62 m`；
- 30,000 步最佳模型及指标元数据已自动保存。

## 50 万步验收指标

优先查看：

1. `eval/success_rate`；
2. `eval/collision_rate`；
3. `eval/final_goal_distance`；
4. `eval/return`；
5. `actor_sat_pct`；
6. `latent_std_mean`；
7. `reference_loss` 和 `reference_endpoint_error`；
8. `async_cache_age_steps` 和 `async_high_level_refreshed`；
9. `episode/length`；
10. `env/goal_distance`。

结构验收要求：

- `async_cache_age_steps` 应主要位于 0 至 7；
- `async_high_level_refreshed` 应周期性为 1；
- 正常运行时 `async_safe_fallback` 应为 0；
- `latent_std_mean` 不应持续单调放大或趋近 0；
- `actor_sat_pct` 不应长期接近 1；
- 参考损失下降后应保持有限且稳定。

性能验收不能只看回报。至少要求最终距离明显下降，并结合成功率、碰撞率和
回合终止原因判断是否真正学会导航。
